Leonida Trophy Codex is an offline guide and tracker for all 55 GTA VI trophies on PS5: every official name, description and grade, a cited step-by-step guide for each trophy, a roadmap to the platinum, missable flags with last-chance windows, and a checklist that saves in your browser and exports to a file.

## Run it

```sh
node serve.ts
```
